El firmware para ESP32 todavía no está publicado. Esta página explicará cómo cargarlo en la placa
y cómo configurar su conexión a la red y al servidor.
:::

Mientras tanto, el nodo simulado (`pnpm sim-node`) se comporta como un ESP32 y permite probar la
plataforma sin placa.
