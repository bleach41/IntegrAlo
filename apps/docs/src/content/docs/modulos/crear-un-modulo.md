---
title: Crear un módulo
description: Cómo se describe un módulo nuevo para IntegrAlo.
sidebar:
  order: 1
---

Cada módulo se describe con un manifiesto, `manifest.json`, dentro de su carpeta en `modules/`. El
del módulo de temperatura está en `modules/temperature/manifest.json` y sirve de ejemplo.

Para comprobar que todos los manifiestos son válidos:

```bash
pnpm check:manifests
```
